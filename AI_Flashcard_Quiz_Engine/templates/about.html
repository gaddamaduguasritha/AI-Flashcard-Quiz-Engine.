About This Project

AI Flashcard and Quiz Engine is a Flask-based web application that converts lecture notes into interactive study material.

How it works

  1. The student pastes notes or uploads a TXT, PDF, or DOCX file.
  2. The application extracts and cleans the text.
  3. It identifies sentences, keywords, definitions, and important facts.
  4. It generates flashcards, MCQs, and true/false questions from that content.
  5. The student can practice, submit a quiz, view a score, and review explanations.
  6. All notes, flashcards, quizzes, and attempts are stored in SQLite.

Local NLP techniques

  • Sentence tokenization using punctuation-aware rules
  • Stop-word filtering and keyword frequency analysis
  • Definition detection using linguistic patterns
  • Sentence ranking based on keyword density and position
  • Rule-based cloze, MCQ, and true/false generation

Optional AI Mode

The application can optionally use an OpenAI-compatible chat completion API. If no API key is configured, it automatically uses the offline local NLP engine.
